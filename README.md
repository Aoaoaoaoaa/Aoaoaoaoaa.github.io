# RansomKains.com

A static personal portfolio site for Ransom Kains.

## Files
- `index.html` - website structure/content
- `styles.css` - visual design and responsive layout

## Deploy
This can be hosted free with GitHub Pages or Vercel.

Before publishing:
1. Replace the LinkedIn and GitHub placeholder links.
2. Add a real resume link if desired.
3. Change the contact email if you choose a different address.
4. Add project photos/screenshots as projects become available.
5. Connect the RansomKains.com DNS records to the chosen host.
